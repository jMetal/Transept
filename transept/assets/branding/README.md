# Transept logo

- `transept_mark.svg`: the mark alone, for the browser tab and small sizes.
- `transept_wordmark.svg`: the mark and the name, for the top of every page.

The mark is a few rows of an alignment, with gaps, crossed by one column in saffron: the residues
that Transept places together. Colours: aubergine ink `#2D1E3B`, terracotta `#A9432A`, saffron `#E0A21B` on
`#F8E7BF`. Released under the licence of the repository (GPL-3.0).
