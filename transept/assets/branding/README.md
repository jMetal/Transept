# Transept logo

- `transept_mark.svg`: the mark alone, for the browser tab and small sizes.
- `transept_wordmark.svg`: the mark and the name, for the top of every page.

The mark is a few rows of an alignment, with gaps, crossed by one column in amber: the residues
that Transept places together. Colours: ink `#12324A`, membrane `#1F7A8C`, amber `#C77D0A` on
`#FBEBD0`. Released under the licence of the repository (GPL-3.0).
